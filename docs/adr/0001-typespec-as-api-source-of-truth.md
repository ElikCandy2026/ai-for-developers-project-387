# TypeSpec contract as the single source of truth

API is defined in `contract/main.tsp`, and everything else is generated from it: the
OpenAPI spec, the Spring interfaces and DTOs under
`backend/target/generated-sources/openapi`, and the TypeScript SDK under
`frontend/src/api/generated`. We rejected hand-written server DTOs and a hand-written
client because three copies of the same model drift apart; now a contract change is
one edit plus `make generate`, and compilation fails wherever the code no longer
matches. The OpenAPI file and the TS SDK are committed (so the frontend builds without
running TypeSpec), while the server sources are regenerated by Maven on every
`generate-sources`.
