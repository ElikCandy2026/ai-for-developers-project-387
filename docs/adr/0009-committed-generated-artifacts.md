# Committed generated artifacts, uncommitted build output

`contract/main.tsp` is the only source of truth. The OpenAPI file and the TypeScript
SDK are committed so the backend builds without Node and the frontend without
TypeSpec; the server sources are regenerated by Maven from the committed OpenAPI. The
built frontend is not committed: Vite writes to `frontend/dist`, Maven copies it into
the build output during `process-resources`, and the jar is the only deployable
artifact.

`make check-generated` fails when the committed OpenAPI or SDK differs from a fresh
`tsp compile`; `make verify` runs that gate, the frontend build and the backend tests,
and CI runs the same command. Node and Java versions are pinned so the generated
output does not depend on the machine.
